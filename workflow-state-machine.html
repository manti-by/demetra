How to read

Solid arrows are normal transitions.
Dashed-loop inside Build/Plan means “feed current_task back to agent”.
Awaiting Input is a sink — requires human Linear comment / retry.
Budgets guard infinite loops: MAX_PLAN_ATTEMPTS, MAX_BUILD_ATTEMPTS, MAX_REVIEW_ATTEMPTS, MAX_RUN_ATTEMPTS (watcher), MAX_LISTENER_ATTEMPTS.
